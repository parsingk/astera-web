# Astera 홍보 웹사이트 — 첫 시안

2026-09-21. 루트: `D:\parsingk\astera-web`.

## 목적과 범위

Claude Code와 Codex를 사용하는 개발자가 Astera의 역할을 이해하고, 실제 화면과 데모를 확인한 뒤 다운로드 페이지로 이동하는 단일 페이지 시안. 정적 HTML/CSS/JavaScript이며 배포나 운영 프레임워크 선택은 이번 범위에 포함하지 않는다.

## 근거

- 제품: `D:\parsingk\astera\README.md`, `README.ko.md`, `package.json`, `src/core/theme/themes.ts`.
- 이미지와 영상: Astera의 기존 `assets` 폴더. 로고: `resources/logo-source.png`. 원본을 그대로 복사했다.
- 참고: https://www.onorca.dev/ — 2026-09-21 확인. 큰 제품 미리보기, 기능 탐색, 다운로드 동선을 참고한다. Orca의 카피, 수치, 후기, 로고는 사용하지 않는다.

## 검토한 방향

1. **Daylight workspace (초기 시안)**: 밝은 바탕, 남색 타이포그래피, 큰 실제 제품 화면. 설명의 가독성이 높고 앱 화면이 선명하게 구분된다.
2. **Night observatory (현재 기본값)**: 짙은 남색 바탕과 별빛 포인트. 기존 로고와 밀접하며 앱 프레임의 경계와 빛으로 배경과 구분한다.
3. **Product manual**: 흑백과 기능 중심의 밀도 높은 구성. 정보 전달에 강하지만 첫 방문의 브랜드 인상은 약하다.

사용자가 처음에는 **밝은 배경 + 남색 제품 화면, 영어 중심**을 선택했고, 두 시안을 비교한 뒤 **다크 모드를 기본값**으로 확정했다. 헤드라인은 “Step away. Keep building.”이며, 라이트 버전도 전환해서 비교할 수 있다.

## 디자인 토큰

- Canvas `#f7f8fc`: 차가운 백색. Paper `#ffffff`: 콘텐츠 표면.
- Ink `#19213b`: 제목과 본문. Muted `#657087`: 보조 문장.
- Orbit `#535bd5`: 주요 동작. Line `#e0e4f0`: 경계. Soft `#eef0f8`: 보조 표면.
- 영문 페이지와 브랜드: Public Sans. 폰트와 OFL 라이선스는 로컬에 포함한다.
- 데스크톱 본문 폭 1160px, 두 줄의 큰 영문 제목, 넉넉한 섹션 간격. 모바일은 1열로 전환한다.
- 브랜드의 궤도는 첫 화면의 한 가지 시각적 포인트로 제한한다. 실제 이미지의 색과 내용을 수정하지 않는다.

## 정확성 원칙

- 지원 에이전트는 Claude Code와 Codex로 한정한다.
- 무제한 사용이나 성능 배수, 이용자 수, 고객 후기, 보장된 작업 완료를 주장하지 않는다.
- 계정 자동 전환은 등록된 사용 가능한 계정이 있을 때 이루어진다.
- 자동 수정에는 완료 조건과 재시도 한도가 있다.
- 데모 영상은 기존 제품 녹화다. 웹페이지의 기능 설명용 다이어그램은 실제 앱 UI로 표시하지 않는다.
- 다운로드 버튼은 GitHub Releases로 이동한다. 설치 파일을 직접 내려받는다고 표시하지 않는다.
- Astera는 Apache-2.0 오픈소스이며 Claude Code/Codex의 이용 요금은 별도다.

1. 실제 앱 이미지, 원본 로고, 데모 영상이 로컬에서 로드된다.
2. 대화/터미널 화면 전환, 데모 대화상자, FAQ, 메뉴, 명암 비교가 동작한다.
3. 1440px, 768px, 390px, 320px 폭에서 레이아웃을 검토한다.
4. 페이지 콘솔 및 네트워크 오류를 확인하고 키보드 포커스와 모션 감소 설정을 고려한다.
5. 실행 방법과 시안의 남은 결정을 기록한다.

## 검증 결과

- 1440 / 768 / 390 / 320 CSS px iframe에서 가로 넘침 0건, 이미지 누락 0건, 내부 앵커 누락 0건. Public Sans 두 굵기 모두 로드됨.
- `design/review.html`에서 실제 페이지의 상호작용 17개 통과. 미리보기 전환, 확대 창, 영상 메타데이터와 재생 진행, 닫기 시 재생 정리, FAQ, 모바일 메뉴, 테마 전환을 확인했다.
- 최초 검증에서 닫힘 이벤트가 지연되어 미디어 정리가 늦어지는 문제를 재현했다. 닫기/배경 클릭/취소 동작이 같은 정리 함수를 즉시 실행하도록 수정한 뒤 해당 검사가 통과했다.
- 기본 페이지를 다시 로드했을 때 콘솔 오류와 네트워크 오류는 없었다. 미디어 검사에서 로드 중인 영상을 곧바로 닫으면 취소된 미디어 요청이 `ERR_FAILED`로 기록됐다. 세 영상 모두 메타데이터가 로드됐으며 Jobs 영상은 재생 시간이 진행되는 것을 확인했다.
- `node --check main.js` 통과. 로컬 참조, 중복 ID, 단일 h1, 영문 카피 검사 통과. 이미지·영상 5개의 SHA-256이 앱 원본과 일치한다.
- `design/desktop.png`, `design/mobile-review.png`에 확인한 캡처를 보관했다. 마지막 추가 캡처는 Astera 브라우저가 `screenshot: the page did not paint within 5 s — the window may be minimised`를 반환하여 중단했다.
- 키보드 포커스 스타일과 reduced-motion CSS를 구현했다. 키보드만으로 전체 흐름을 탐색하는 검증 및 다른 브라우저/실기기 검증은 수행하지 않았다.

## 다음 검토

### 다크 시안 추가 — 2026-09-21

- 사용자 요청: “어두운 배경으로도 있으면 좋을 것 같다”. 기존 영문 구성에 짙은 남색 버전을 추가했다.
- 배경 `#0b1020`, 카드 `#131b30`, 본문 `#eef1ff`, 보조 글자 `#abb5cc`, 라벤더 액센트 `#b1b5ff`. 계정 경고, 아바타, 앱 프레임, 궤도도 다크 배경에 맞췄다.
- `?theme=dark` / `?theme=light`로 처음부터 원하는 시안을 연다. 상단·하단 전환 버튼을 동기화하고, URL에 선택을 반영해 새로고침 시 유지한다. 사용자 선택에 따라 쿼리가 없으면 다크가 기본값이며, `?theme=light`일 때 라이트로 시작한다. 비교 페이지도 같은 규칙을 따른다.
- 비교 페이지에도 Light/Dark 선택을 제공한다.
- 변경 전 기존 상호작용 17개 통과. 변경 후 상호작용 20개 통과, 양쪽 테마의 1440/768/390/320px에서 가로 넘침·누락 이미지·누락 앵커 0건. 상단/하단 버튼 상태 및 URL 동기화, 라이트/다크 전환 후 새로고침 확인. 기본 페이지 콘솔·네트워크 오류 없음. `node --check main.js` 통과.
- 다크 데스크톱·모바일·기능 영역을 실제 Astera 브라우저에서 확인하고 `design/dark-*.png`로 저장했다. 이전 시안의 캡처는 비교용으로 유지한다.
