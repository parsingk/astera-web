Astera는 어떤 앱인가요?

Astera는 Claude Code와 Codex를 위한 데스크톱 작업 공간입니다. Smart Resume로 계정 사이에 맥락을 전달하고, Jobs로 협업을 시각화하며, 검사·리뷰 결과로 진행을 확인합니다. 로컬 호스트는 자신이 관리하는 세션을 앱 재시작 중에도 유지합니다.

무료인가요?

네. Astera는 Apache-2.0 라이선스의 무료 오픈소스입니다. Claude Code와 Codex는 본인의 계정으로 이용하며, 해당 서비스의 이용 요금은 별도입니다.

어떤 운영체제를 지원하나요?

Windows 10·11, macOS 12 이상, Ubuntu 22.04·Debian 12 이상을 지원합니다. 운영체제별 설치 방법과 릴리스 안내는 설치 가이드에서 확인하세요.

쓰던 계정을 연결할 수 있나요?

네. 설치된 Claude Code 또는 Codex CLI와 기존 계정을 연결하세요. 계정을 여러 개 등록하면 사용량 한도에 도달했을 때 같은 서비스의 다음 사용 가능한 계정에서 작업을 이어갈 수 있습니다.

모든 작업이 자동으로 끝나나요?

완료가 보장되지는 않습니다. Jobs는 지정한 완료 조건과 재시도 한도 안에서 수정과 검사를 반복합니다. 사용자의 판단이 필요한 질문은 답변을 기다립니다.
