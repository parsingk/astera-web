Claude Code usage limits: save your work and resume.

What the limits are, how to see them coming, and how to pick the work back up without losing your place.

How Claude Code’s limits work

On a Claude subscription, Claude Code does not have a separate allowance. According to Anthropic’s help center, your use of Claude chat, Claude Code, and Claude Desktop all counts toward the same usage limit. Paid plans have two kinds of limits:

  • A session limit that starts with your first message and resets five hours later.
  • A weekly limit that resets at a fixed time each week assigned to your account.

Plans differ. Anthropic does not publish message counts, because usage varies with message length, attached files, conversation length, and the model or feature you use. Check the current rules for your plan in How do usage and length limits work? and Use Claude Code with your plan.

A usage limit is not an API rate limit

A plan’s usage limit resets at a time Claude Code shows you. An API rate limit is different: it applies to API keys and cloud providers, is measured per minute, and returns a 429 error. Claude Code’s messages tell them apart, for example You've hit your session limit · resets 3:45pm for a plan limit, and Request rejected (429) for an API key’s rate limit. Claude Code error reference

Check how much you have left

  • In Claude Code, run /usage to see plan usage limits and activity.
  • On the web, open Settings → Usage to see the current session and your next weekly reset.
  • Claude Code warns before the limit, for example You've used 85% of your session limit · resets 3:45pm.

If an ANTHROPIC_API_KEY environment variable is set, Claude Code uses that key instead of your subscription and you are billed for API usage. Check it before assuming a limit message is about your plan.

Save the work before the limit arrives

A limit stops new requests, not the files already on disk. A few habits make any way of resuming easier:

  • Keep the requirements the agent must follow in project files such as CLAUDE.md, not only in the conversation.
  • Ask the agent to commit or summarize progress at natural stopping points, so the next session can read where things stand.
  • Split large work into tasks with clear checks, so a restart begins from a known state.
  • When the warning appears, ask for a short handoff note: what is done, what is next, and how to verify it.

Your options when the limit is reached

Anthropic lists these options. Each is described on its own help pages:

  • Wait for the reset. Recent versions of Claude Code can wait in the open session and continue on their own after the limit resets; this is on by default for interactive sessions signed in with a Claude subscription. Wait for a usage limit to reset
  • Use usage credits. Requests continue on pay-as-you-go credits billed at API rates. Manage usage credits
  • Upgrade your plan, or use a Claude Console account with API billing for intensive work.

Inside Claude Code, /rate-limit-options shows the ways to keep working that apply to you.

Where Astera helps

Astera does not raise, pool, or bypass any plan’s limit. It helps you keep the work in order around a limit:

Wait and resume, even with the app closed

Astera detects a limit from the session’s transcript and works out the reset time. With a single account, the session option Wait for the limit to reset, then resume automatically resumes it when the limit resets. Astera Host can keep the session running after you quit the app; keep the computer awake. Account rolling in the guide

Know when it happens

Slack notifications can tell you when a limit is hit or a turn finishes, and you can reply into the session from Slack. Slack updates and replies

Hand the next session a checkpoint

Smart Resume can start the next session with a compact summary of the requests, changed files, and last command, instead of replaying a long conversation.

Accounts you are entitled to use

If you have more than one account that is yours to use for this work, account rolling can continue a session on the next one. Every account keeps its own limits. Follow each provider’s terms: Anthropic’s Usage Policy prohibits creating multiple accounts to circumvent its guardrails or restrictions, and its Claude Code terms say that advertised plan limits assume ordinary, individual usage.

Codex has limits too

Codex on a ChatGPT plan has its own allowance: local messages and cloud chats share it, and weekly limits may also apply. In a Codex CLI session, /status shows what remains. OpenAI: Codex pricing and limits · Codex in Astera

About this guide
