Codex CLI에 작업 공간을 더하세요

Astera는 컴퓨터에 설치된 codex 명령을 실행하고 세션마다 데스크톱 창 안에 자리를 줍니다. 그 옆에 Claude Code 세션, 파일, 워크트리가 함께 놓입니다. Codex는 터미널에서 쓰던 방식 그대로 쓰고 Astera는 계정 관리, 도구 공유, 검사, 변경 기록을 더합니다.

Astera는 OpenAI의 Codex 앱이 아닙니다. OpenAI가 만들거나 제휴한 제품이 아닌 독립 오픈소스 프로젝트입니다.

Astera에서 Codex로 할 수 있는 일

터미널 또는 대화 세션

Codex 고유의 터미널 화면으로 실행하거나, 질문과 승인이 카드로 오는 대화로 실행하세요. 세션 종류는 만들 때 정한 대로 유지됩니다. 가이드: 터미널과 대화

Codex 계정 여러 개를 따로

Codex 계정마다 별도의 CODEX_HOME으로 실행합니다. 계정을 추가할 때 기본 계정에서 설정 가져오기를 쓰면 Codex 설정을 그 계정의 config.toml에 합치고 주석과 관련 없는 항목은 그대로 둡니다.

MCP 서버, 스킬, 플러그인 공유

설정 → MCP & Skills에서 MCP 서버와 스킬을 한 번 고르면 모든 계정의 새 세션에 적용됩니다. 제공자별 지원 범위는 그대로여서 Codex에는 슬래시 명령과 하위 에이전트가 없습니다. 공유한 Claude Code 플러그인은 모든 Codex 계정에도 설치됩니다. 이때 에이전트는 빠지고 명령은 <plugin>:source-command-<name> 이름의 스킬이 됩니다. 가이드: MCP & Skills

작업을 폴더 안에 두는 Sandbox

에이전트 프로필에서 Sandbox에서 실행을 켜면 Codex 자체 Sandbox를 씁니다. 작업 폴더와 임시 폴더 밖에는 쓰지 못하게 하고 로그인 파일을 막습니다. Codex 0.160.0 이상이 필요하며 Windows에서는 Codex 계정마다 관리자 권한 요청이 뜨는 설정하기를 한 번 실행해야 합니다. 네트워크는 그대로 쓸 수 있습니다. 가이드: Sandbox

같은 작업에 Codex와 Claude Code를 함께

Job 하나에서 어떤 작업은 Codex에게, 어떤 작업은 Claude Code에게 맡기고 각 결과를 다른 제공자의 모델에게 리뷰하게 할 수 있습니다. 교차 리뷰는 리뷰하는 제공자의 사용량을 씁니다. Jobs로 하는 에이전트 오케스트레이션

사용량 한도 뒤에도 이어 가기

Codex 세션이 한도에 닿으면 Astera는 초기화를 기다렸다가 재개하거나, 등록해 둔 다른 Codex 계정 중 본인이 쓸 권한이 있는 계정에서 이어 갈 수 있습니다. 한도는 계정마다 따로 적용됩니다. Smart Resume을 쓰면 다음 세션에 간결한 체크포인트를 넘깁니다.

요구 사항과 한계

  • Windows 10·11, macOS 12 이상, Ubuntu 22.04·Debian 12 이상.
  • Codex CLI를 설치하고 로그인해야 합니다. Sandbox는 Codex 0.160.0 이상이 필요합니다.
  • Astera는 Apache-2.0 라이선스의 무료 오픈소스입니다. Codex 사용량은 본인의 OpenAI 요금제에서 차감되며 로컬 메시지와 클라우드 대화가 요금제 사용량을 함께 씁니다. Codex CLI 세션에서 /status를 입력하면 남은 한도를 볼 수 있습니다. OpenAI: Codex 요금과 한도

자주 묻는 질문

Astera가 OpenAI의 Codex 앱인가요?

아닙니다. Astera는 Codex CLI를 실행하는 독립 오픈소스 작업 공간이며 OpenAI가 만들거나 제휴한 제품이 아닙니다.

Codex가 Claude Code의 작업을 리뷰할 수 있나요?

네. Job에서 리뷰를 요청한 작업은 보통 다른 제공자의 모델이 리뷰합니다. 그래서 Claude Code가 한 작업을 Codex가 리뷰하고 반대로도 할 수 있습니다. 리뷰할 제공자의 계정이 있어야 합니다.

Codex와 Claude Code가 계정을 함께 쓰나요?

아닙니다. Astera의 계정은 한 제공자에 속합니다. 계정 전환도 같은 제공자의 다른 계정으로만 세션을 옮깁니다.
