When one terminal is not enough

Claude Code is a command-line agent. Once you run it on several projects or tasks at the same time, the work spreads across terminal windows, and each window has its own context, sign-in, and usage limit. Astera puts those sessions in one desktop window, keeps every account in its own configuration folder, and keeps a record of what each session changed.

What Astera adds around Claude Code

Several sessions, side by side

Open a session for each task and arrange them in split panes. A session is either a Terminal, with Claude Code’s own interface, or a Chat, where questions and approvals arrive as cards and the model and permission mode sit beside the message box. A session keeps the type it was created with. Terminal and Chat in the guide

Accounts kept apart, tools shared

Each Claude account runs with its own CLAUDE_CONFIG_DIR, so sign-ins and settings do not mix. In Settings → MCP & Skills you pick MCP servers, skills, commands, agents, and Claude Code plugins once, and new sessions on every account get them. Share tools across accounts

Work that continues after a usage limit

When a session reaches a usage limit, Astera reads the reset time from the transcript. With one account, the session can wait and resume when the limit resets. If you have registered more than one account that you are entitled to use, account rolling can continue the session on the next one; every account keeps its own limits. Smart Resume can give the next session a compact checkpoint instead of the whole conversation. Working with Claude Code usage limits

Sessions that outlive the window

A separate local process, Astera Host, can own Terminal and Chat sessions, so quitting the app leaves them running. Reopen Astera to reconnect to the live session. Keep the computer awake while work runs. What stays running

Results that are checked

For larger work, a Job splits an objective into tasks for Claude Code and Codex workers, runs your build and test checks, and can ask the other provider’s model to review the result before the work counts as done. Agent orchestration with Jobs

Get started

  1. Install Claude Code

    Install the Claude Code CLI so the claude command is on your PATH. Astera starts that command; it does not include Claude Code.

  2. Install Astera

    Download the installer for your operating system. macOS builds are not notarized yet, so the first launch needs the quarantine flag cleared, and Windows SmartScreen may warn on first run. Installation steps

  3. Add your account

    In Accounts, use Auto-detect to find accounts you already use, or choose Add account and finish Claude Code’s sign-in when prompted.

  4. Start a session

    Open New session, choose the project folder and account, pick Terminal or Chat, and click Start. Describe the result you want and how to check it. Your first session

Requirements and limits

  • Windows 10 or 11, macOS 12 or later, or Ubuntu 22.04 / Debian 12 or later. Astera is a desktop app; you can follow sessions and reply from Slack on your phone.
  • Claude Code installed and signed in. Astera is free and open source (Apache-2.0). Claude usage counts against your own Claude plan or is billed to your API account.
  • Your plan’s limits still apply. Anthropic counts Claude Code and Claude chat toward the same usage limits. Anthropic: Claude Code with your plan
  • Astera starts the claude command installed on your computer, signed in with your own account, so Anthropic’s terms for Claude Code apply as they do in a terminal. Claude Code legal and compliance

Questions

Is Astera the Claude desktop app?

No. Claude Desktop is Anthropic’s chat app. Astera is an independent, open-source workspace that runs the Claude Code CLI. It is not made by or affiliated with Anthropic.

Does Astera change how Claude Code works?

Astera starts Claude Code in the project folder you choose, with that account’s own configuration folder. In a Terminal session you use Claude Code’s own interface. In a Chat session, Astera shows Claude Code’s questions and approvals as cards.

Can I use Codex in the same window?

Yes. Codex sessions run beside Claude Code sessions, and a Job can give tasks to both. Codex in Astera

What does it cost?

Astera is free. Model usage counts against your Claude plan or is billed to your API account, just as it would in a terminal.
