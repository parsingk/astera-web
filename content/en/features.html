Where to start

  • Usage limits stop you mid-task. Claude Code usage limits explains how the limits work, and Smart Resume hands the next session a checkpoint instead of the whole conversation.
  • You want results that are checked, not assumed. Agent orchestration runs tasks with checks and a review by the other provider’s model, and GitHub issue to pull request carries the work through CI.
  • You want to automate from a terminal or another agent. Use the headless CLI or MCP.
  • Your agents should run on another computer. See Remote Runtime.
  • You need to see or limit what agents do. See audit logs, Rules, and the sandbox.

New to Astera? Start with the page for your agent, Claude Code or Codex, or read the full guide.
