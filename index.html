Ask us on GitHub
What is Astera?

Astera is a desktop workspace for running and orchestrating Claude Code and Codex sessions. It brings account rolling, scheduling, git worktrees, and completion checks into one app.

Is Astera free?

Yes. Astera is free and open source under Apache-2.0. You bring your own Claude Code or Codex accounts. Any fees for those services are separate.

Which platforms are supported?

Windows 10 and 11, macOS 12 or later, and Ubuntu 22.04 / Debian 12 or later. See the installation guide for platform-specific steps and current release notes.

Can I use my existing accounts?

Yes. Connect your installed Claude Code or Codex CLI and the accounts you already use. Add multiple accounts, and Astera can resume work on the next available account for the same service when a usage limit is reached.

Will every job finish automatically?

Completion is not guaranteed. Jobs can repeat repairs and checks within the completion policy and retry limit you set. Questions that need your judgment still wait for your answer.
