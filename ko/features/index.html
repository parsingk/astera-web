Astera가 Claude Code와 Codex에 더하는 것

Astera는 Claude Code와 Codex를 실행하는 데스크톱 작업 공간입니다. 페이지마다 한 기능을 맡아 무엇을 하는지, 어떻게 설정하는지, 한계가 어디까지인지 설명합니다.

기능 전체 보기

에이전트 오케스트레이션코딩 작업을 Claude Code와 Codex 워커가 맡을 작업 그래프로 나누세요. Astera는 검사와 다른 제공자의 리뷰를 통과해야 완료로 봅니다.읽기 Smart ResumeSmart Resume은 대화 전체를 다시 불러오는 대신, 지금까지의 작업을 담은 간결한 체크포인트를 다음 세션에 넘깁니다.읽기 GitHub 이슈에서 PR까지코딩 에이전트의 작업을 GitHub 이슈에서 초안 PR, CI, 수정, 다른 모델의 리뷰까지 이어 갑니다. 병합할 준비가 되면 Astera가 알려 줍니다.읽기 헤드리스 CLIastera 명령으로 어느 셸이나 스크립트에서든 Claude Code와 Codex 세션과 Job을 시작하세요. JSON 출력, 코드마다 뜻이 하나인 종료 코드, 앱을 닫아도 이어지는 작업.읽기 MCPMCP 서버, 스킬, 플러그인을 모든 Claude Code·Codex 계정에 공유하고 MCP 클라이언트가 Astera Job을 만들고 실행하고 따라가게 하세요.읽기 Remote RuntimeAstera Remote Runtime은 LAN, VPN, Tailscale로 페어링한 컴퓨터에서 코딩 에이전트와 Job을 실행합니다. 고정 TLS와 회수할 수 있는 권한을 쓰며 중계 서비스나 호스팅 서비스는 없습니다.읽기 감사 기록과 SandboxClaude Code와 Codex 에이전트가 한 일을 감사 기록으로 보고 Rules로 호출을 막으세요. 자격 증명은 세션 밖에 두고 에이전트는 Sandbox에서 실행하세요. 플랫폼별 한계도 정리했습니다.읽기

어디서부터 볼까요

  • 작업 중간에 사용량 한도에 막힌다면. Claude Code 사용량 한도에서 한도가 어떻게 적용되는지 보고 Smart Resume으로 다음 세션에 대화 전체 대신 체크포인트를 넘기세요.
  • 결과를 짐작이 아니라 검사로 확인하고 싶다면. 에이전트 오케스트레이션은 검사와 다른 제공자 모델의 리뷰를 거쳐 작업을 끝내고 GitHub 이슈에서 PR까지는 그 작업을 CI까지 이어 갑니다.
  • 터미널이나 다른 에이전트로 자동화하고 싶다면. 헤드리스 CLI나 MCP를 쓰세요.
  • 에이전트를 다른 컴퓨터에서 돌려야 한다면. Remote Runtime을 보세요.
  • 에이전트가 하는 일을 보거나 제한해야 한다면. 감사 기록, Rules, Sandbox를 보세요.

Astera가 처음이라면 쓰는 에이전트에 맞춰 Claude Code나 Codex 페이지부터 보거나 전체 가이드를 읽어 보세요.

내 프로젝트에서 Astera를 써 보세요.

Astera는 Apache-2.0 라이선스의 무료 오픈소스입니다. 지금 쓰는 Claude Code와 Codex CLI를 그대로 실행하므로 모델 사용량은 본인의 Anthropic 또는 OpenAI 요금제에서 차감됩니다.
