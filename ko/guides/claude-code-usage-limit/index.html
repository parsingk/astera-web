Astera/실전 가이드

Claude Code 사용량 한도: 작업을 남기고 이어 가기.

한도가 무엇인지, 다가오는 한도를 어떻게 알아채는지, 하던 작업을 잃지 않고 어떻게 다시 시작하는지 설명합니다.

Claude Code 한도는 이렇게 적용됩니다

Claude 구독으로 쓰는 Claude Code에는 따로 떼어 둔 사용량이 없습니다. Anthropic 도움말에 따르면 Claude 채팅, Claude Code, Claude Desktop 사용량은 모두 같은 한도로 계산됩니다. 유료 요금제에는 한도가 두 가지 있습니다.

  • 세션 한도: 첫 메시지를 보낸 때부터 시작해 5시간 뒤에 초기화됩니다.
  • 주간 한도: 계정마다 정해진 시각에 매주 초기화됩니다.

요금제마다 규칙이 다릅니다. 사용량은 메시지 길이, 첨부 파일, 대화 길이, 쓰는 모델이나 기능에 따라 달라지기 때문에 Anthropic은 메시지 수를 공개하지 않습니다. 내 요금제의 현재 규칙은 사용량과 길이 한도 안내와 요금제로 Claude Code 사용하기에서 확인하세요.

사용량 한도와 API 속도 제한은 다릅니다

요금제의 사용량 한도는 Claude Code가 알려 주는 시각에 초기화됩니다. API 속도 제한은 다릅니다. API 키와 클라우드 제공자에 적용되고 분 단위로 계산하며 429 오류를 돌려줍니다. Claude Code 메시지로 둘을 구분할 수 있습니다. 요금제 한도는 You've hit your session limit · resets 3:45pm처럼, API 키의 속도 제한은 Request rejected (429)처럼 표시됩니다. Claude Code 오류 안내

남은 사용량 확인하기

  • Claude Code에서 /usage를 실행하면 요금제 한도와 사용 현황을 볼 수 있습니다.
  • 웹에서는 Settings → Usage에서 현재 세션 사용량과 다음 주간 초기화 시각을 확인합니다.
  • Claude Code는 한도에 닿기 전에 You've used 85% of your session limit · resets 3:45pm처럼 미리 알려 줍니다.

ANTHROPIC_API_KEY 환경 변수가 설정돼 있으면 Claude Code는 구독 대신 그 키를 쓰고 API 사용량으로 요금이 청구됩니다. 한도 메시지가 요금제 이야기라고 단정하기 전에 먼저 확인하세요.

한도가 오기 전에 작업 남겨 두기

한도가 막는 것은 새 요청이지, 이미 디스크에 있는 파일이 아닙니다. 몇 가지 습관만 들여도 어떤 방식으로든 다시 시작하기 쉬워집니다.

  • 에이전트가 따라야 할 요구 사항은 대화에만 두지 말고 CLAUDE.md 같은 프로젝트 파일에 적어 두세요.
  • 일이 한 단락 끝날 때마다 에이전트에게 커밋하거나 진행 상황을 요약하게 하세요. 다음 세션이 어디까지 왔는지 읽을 수 있습니다.
  • 큰 작업은 확인 방법이 분명한 작은 작업으로 나누세요. 다시 시작할 때 알려진 상태에서 출발할 수 있습니다.
  • 경고가 뜨면 짧은 인계 메모를 부탁하세요. 끝난 일, 다음 할 일, 확인 방법이면 충분합니다.

한도에 닿았을 때 고를 수 있는 방법

Anthropic은 아래 방법을 안내합니다. 자세한 내용은 각 도움말을 보세요.

  • 초기화 기다리기. 최신 Claude Code는 열린 세션에서 기다렸다가 한도가 풀리면 스스로 작업을 이어 갑니다. Claude 구독으로 로그인한 대화형 세션에서는 기본으로 켜져 있습니다. 사용량 한도 초기화 기다리기
  • 사용 크레딧 쓰기. API 요금으로 청구되는 종량제 크레딧으로 요청을 계속합니다. 사용 크레딧 관리
  • 요금제 올리기, 또는 집중 작업에는 API 요금을 쓰는 Claude Console 계정 사용하기.

Claude Code에서 /rate-limit-options를 실행하면 지금 쓸 수 있는 방법을 보여 줍니다.

Astera가 돕는 부분

Astera는 어떤 요금제의 한도도 늘리거나, 합치거나, 우회하지 않습니다. 한도 전후로 작업이 흐트러지지 않게 돕습니다.

앱을 닫아도 기다렸다가 재개

Astera는 세션 기록에서 한도 도달을 감지하고 초기화 시각을 계산합니다. 계정이 하나일 때 세션의 한도 도달 시 리셋까지 대기 후 자동 재개 옵션을 켜 두면, 한도가 풀릴 때 세션을 재개합니다. 앱을 종료해도 Astera Host가 세션을 계속 실행할 수 있으니 컴퓨터가 잠들지 않게만 해 두세요. 가이드: 계정 자동 전환

한도에 닿으면 알림

Slack 알림으로 한도에 닿았거나 턴이 끝났을 때 소식을 받고 Slack에서 세션에 답할 수 있습니다. Slack 알림과 답장

다음 세션에 체크포인트 넘기기

Smart Resume은 긴 대화를 다시 불러오는 대신 요청, 바뀐 파일, 마지막 명령을 간결하게 정리해 다음 세션을 시작합니다.

본인이 쓸 권한이 있는 계정만

이 작업에 쓸 수 있는 본인 계정이 두 개 이상이라면 계정 전환으로 다음 계정에서 세션을 이어 갈 수 있습니다. 한도는 계정마다 따로 적용됩니다. 제공사의 약관을 지켜 주세요. Anthropic 이용 정책은 보호 장치나 제한을 피하려고 계정을 여러 개 만드는 행위를 금지합니다. Claude Code 약관은 요금제에 안내된 한도가 일반적인 개인 사용을 전제로 한다고 밝힙니다.

Codex에도 한도가 있습니다

ChatGPT 요금제로 쓰는 Codex에는 별도의 사용량이 있습니다. 로컬 메시지와 클라우드 대화가 이를 함께 쓰고 주간 한도가 붙을 수도 있습니다. Codex CLI 세션에서 /status를 입력하면 남은 양이 보입니다. OpenAI: Codex 요금과 한도 · Astera에서 Codex 쓰기

이 가이드에 대해

제공사 관련 내용은 2026-11-25에 위에 링크한 Anthropic과 OpenAI 페이지로, Astera 동작은 Astera 1.5.5로 확인했습니다. 이 페이지를 위해 실제로 사용량 한도에 닿아 보지는 않았습니다. 요금제와 한도는 바뀔 수 있으니 제공사 페이지를 기준으로 삼으세요.

내 프로젝트에서 Astera를 써 보세요.

Astera는 Apache-2.0 라이선스의 무료 오픈소스입니다. 지금 쓰는 Claude Code와 Codex CLI를 그대로 실행하므로 모델 사용량은 본인의 Anthropic 또는 OpenAI 요금제에서 차감됩니다.
